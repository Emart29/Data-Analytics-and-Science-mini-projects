# 🚗 Car Insurance Claim Prediction

## 📊 Project Overview
A logistic regression analysis project using **StatsModels** to predict car insurance claim outcomes. This mini-project identifies the most influential factors in claim filings through single-feature modeling.

## 🎯 Key Features
- **Data Analysis**: Comprehensive EDA and missing value treatment
- **Statistical Modeling**: Single-feature logistic regression for interpretability
- **Feature Ranking**: Identifies best predictors using accuracy metrics
- **Results Export**: Stores best performing feature in structured format

## 🛠 Tech Stack
- **Python** with Pandas, NumPy, StatsModels
- **Jupyter Notebook** for interactive analysis
- **Statistical Modeling** with hypothesis testing

## 📈 Key Results
- **Best Predictor**: driving experience (78% accuracy)
- **Methodology**: 15+ single-feature logistic regression models
- **Output**: `best_feature_df` with top feature and accuracy score
