# Nobel Prize Data Analysis

## 📊 Project Overview
This project analyzes Nobel Prize laureate data from 1901 to 2023 to identify demographic trends and geographical patterns among award recipients.

## 🎯 Key Questions Answered
- Which gender is most commonly awarded Nobel Prizes?
- What is the most common birth country among laureates?
- Which decade had the highest ratio of US-born winners?
- How has the proportion of US-born winners changed over time?

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook

## 📈 Key Findings
- **Male laureates** are the most commonly awarded gender
- **United States of America** is the most common birth country
- **2000s decade** had the highest ratio of US-born winners (42.3%)
- **Upward trend** in US-born winners over time, from 1.8% in 1900s to 42.3% in 2000s
- **Manhattan** shows the largest variability in SAT performance (std dev: 230.29)
